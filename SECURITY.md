# Security Policy

## Supported versions

This project is pre-1.0 and does not yet maintain multiple supported release
lines. Security fixes target the latest revision on `main`. Users should update
to the latest available revision when a security fix is published.

## Reporting a vulnerability

Do not disclose suspected vulnerability details in a public issue, discussion,
pull request, room transcript, or other public artifact.

Use GitHub's [private vulnerability reporting
form](https://github.com/virusimmortal00/AllMyFriendsAreAgents/security/advisories/new).
Reports submitted there are shared privately with repository maintainers.
Alternatively, email [bobby@sayers.io](mailto:bobby@sayers.io). Do not include
vulnerability details in a public request for contact.

Once a private channel is established, include:

- a concise description of the vulnerability and its potential impact;
- affected components, configurations, and revisions;
- minimal reproduction steps or proof-of-concept material;
- known mitigations or workarounds; and
- whether and where the issue has already been disclosed.

Please avoid accessing data that is not your own, disrupting services, or
publishing details before maintainers have had a reasonable opportunity to
investigate and prepare a fix.
