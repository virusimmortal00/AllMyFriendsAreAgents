# Everyday conversation lever study (schema 5)

Jev is the room's advisory reply-routing classifier; see [issue #232](https://github.com/virusimmortal00/AllMyFriendsAreAgents/issues/232) and the [live canary guide](conversation-routing-live-canary.md) for the existing study context.

The [closed plan](conversation-routing-study-large-everyday-v5.json) contains 36 matched pairs, or 72 isolated room cases. It replaces the garden examples for a prospective study while preserving the earlier plan and its historical results. Each pair repeats the same scripted human turns, roster, energy, room identity, terminal instruction, and global actor model. The only treatment difference is one of three factors: Jev question (`current-v1` versus `lean-v1`), optional gate (`current-v1` versus `relevance-v1`, both with the relevance Jev question), or agent base prompt (`current-v1` versus `social-v1`). Each factor has 12 pairs, balanced between six everyday-chat and six practical-work profiles, with three AB and three BA orderings within each factor and theme. The frozen seed places prompt/casual-home, gate/handoff-home, and Jev/direct-work in the first three-pair inspection batch. The first two have an optional seat available.

The 36 closed conversation profiles span all seven routing dynamics, one through three roster agents, and one through three human messages. Each prompt supplies enough context to answer without assuming unseen prior discussion. Named addresses use the neutral room cards Riley, Jordan, and Casey; the quoted-name profiles contain those names only inside quoted notes, so their expected direct-target list is empty. Ten gate pairs and ten prompt pairs are non-broadcast with at least one optional participant and a positive optional-seat allowance. Their two broadcast pairs each are explicit negative controls: whole-room invitations require all agents, so the optional gate cannot filter them and the optional-response prompt has no optional seat to influence. One handoff profile asks Riley to solicit Jordan's view while the human directly addresses only Riley, allowing the live run to observe an agent-to-agent invitation. A silent agent is a valid conversational outcome, especially on casual turns. Distinct profile IDs and text-bound digests prevent one pair's prompt from silently standing in for another.

The plan pins `room-v1` and `contribution-first-v1` on both arms. The actor model is supplied once by the runner and must remain the same for all 72 cases. The closed schema rejects missing or duplicated profiles, unknown fields or profile IDs, factor drift, rosters wider than three, and addresses to absent agents. The source-text digest changes if any visible scenario text changes. Existing schema 1–4 plans and their digests remain unchanged.

The reviewed schema-5 plan has order seed `265` and parsed-plan SHA-256 `1a383295b7140df1550687441b3079a295435b09050c6637e29fe4c0fd5f66dc`. The runner requires this exact digest before a live batch. An earlier seed and digest are invalid for this plan.

This file describes a provider-free plan. A dry-run and the separate live runner integration must be audited before any paid execution. Live results and raw conversations belong in private local output, with human grading generated from the completed matched manifests.

## Private review and readout

After all twelve completed three-pair batch manifests have been retained privately, pass each manifest to `scripts/conversation-routing-live-review.ts` as a separate `--manifest` argument. `blind` creates opaque cards and a private map from the matching source directories. The reviewer should use `select-calibration` first: it chooses twelve distinct pairs, four per factor with two everyday and two practical profiles per factor, and one seed-selected trigger per pair. Both arms are present, giving 24 cards. The selection receipt stays private. This calibration sample is for checking how the four quality axes behave under human review; it does not estimate overall prevalence or capture every turn in a long arc.

Use `select-flagged` with the calibration receipt for a separate outcome-conditioned inspection of unanswered required turns. `select-visible` similarly inspects both-visible pairs. Keep these ratings and denominators separate from calibration. `select-everyday-all` optionally writes three factor-specific queues, each with 24 cards, into a private 0700 directory. Together they cover all 72 cases at one seed-selected trigger ordinal per pair. The private receipt maps opaque IDs to factor, pair, and arm; that mapping must not enter a public report. Each queue can be packed, rated, exported, imported, and converted independently. A complete multi-trigger block judgment still requires reviewing its other turns.

For an early stop, supply only the completed leading batch manifests and `--allow-partial true` to `blind`, `select-everyday-all`, `pack`, and `convert`. Partial review requires complete three-pair batches from the committed plan, a shared source and model selection, and no skipped batch. The resulting packs are labeled `PARTIAL DIAGNOSTIC`; pass `--review-set everyday-partial` to `pack` and `convert`. A full `analyzeQualityStudy` readout requires all 36 pairs. Analysis keeps actor delivery, Jev consultation, four judge axes, frame integrity, and human ratings on separate observed denominators; missing ratings stay missing. Raw conversation cards and human ratings remain in private local files, while the scalar analysis output contains no transcript text.
